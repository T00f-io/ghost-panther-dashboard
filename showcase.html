The Brief

Problem → Solution

The Problem

Training 4–5x per week on a structured 90-day program generated detailed session data with nowhere to live efficiently. The existing workflow required dictating notes in Drafts on iOS, running them through a specialized AI agent, manually copying formatted output into Google Sheets, and performing analysis separately.

High friction. Inconsistent logging. No real-time coaching feedback. No trend visibility. Data siloed across multiple tools with no intelligence layer.

The Solution

A full-stack AI-powered personal fitness OS that accepts raw workout notes directly, parses them using the Claude API, stores all training data in a structured PostgreSQL database, and surfaces coaching insights at the session, weekly, and arc level.

One tap from Apple Notes sends a workout through a Cloudflare Worker, through Claude, and into Supabase — then auto-deletes the note. Zero manual data entry. Zero Google Sheets. Real coaching intelligence on every session.
